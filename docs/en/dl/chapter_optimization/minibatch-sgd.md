Thirty-two synthetic airfoil rows have five input columns. After the mean and standard deviation of all rows, each step takes four rows. Four steps run, then one loss uses the last eight rows.

### Batches of four rows

The learning rate is 0.05. The target is centered on the mean of all rows so the large sound column does not blow up the squared loss. Both losses share one line.

```numpy run expect="loss" title="Airfoil steps"
# The first 16 of 32 rows enter the four steps
import numpy as np
import minitorch as mt
x, y = mt.datasets.airfoil()
mu = x.mean(axis=0)
sd = np.where(x.std(axis=0) < 1e-8, 1.0, x.std(axis=0))
xz = (x - mu) / sd
yz = y - y.mean()
w = mt.tensor(np.zeros(xz.shape[1]), requires_grad=True)
b = mt.tensor(np.zeros(1), requires_grad=True)
last = 0.0
for step in range(4):
    xb = xz[step * 4:(step + 1) * 4]
    yb = yz[step * 4:(step + 1) * 4]
    w.grad = None
    b.grad = None
    pred = mt.tensor(xb) @ w + b
    loss = ((pred - mt.tensor(yb)) * (pred - mt.tensor(yb))).mean()
    loss.backward()
    w.data -= 0.05 * w.grad
    b.data -= 0.05 * b.grad
    last = loss.item()
vpred = mt.tensor(xz[24:32]) @ w + b
vloss = ((vpred - mt.tensor(yz[24:32])) * (vpred - mt.tensor(yz[24:32]))).mean()
print("loss", round(last, 4), round(float(vloss.item()), 4))
```
