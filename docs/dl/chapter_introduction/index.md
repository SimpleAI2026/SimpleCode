引言把后面会反复用到的四件事放在同一页：少量数据、一个预测函数、一个标量损失，以及很少的几步更新。具体公式留在各自的章节。

### 从少数样本拟合

一条样本是一组输入，加上希望得到的输出。练习场不会一次放下整库图片或整库句子，只留几十条甚至更少，用来看形状和接口是否接得上。

### 预测写成函数

模型把输入变成预测。最简单的情形是权重和输入做乘加。更复杂的层按后面的章节再加。这一页不给出可以拿去用的权重。

### 损失衡量差多少

损失把预测和目标合成一个标量。分类的例子还会再看对了几条，但通过与否不取决于准确率高不高。输出里能读到损失或形状，这一步就算走到了。

```numpy norun title="引言不计算损失"
# 后文才会打印 loss
print("loss")
```

### 更新只走四步

带训练的节统一用不超过 32 条训练样本、不超过 8 条留出样本，批量取 4，优化只走 4 步。引言本身不循环。下面这段只标明步数。

```numpy norun title="引言不循环更新"
# 四步之后停下
print(4)
```
