后面的公式共用一套说法，避免每个例子换一种称呼。这里只约定怎么读形状和梯度，不推导新的结论。

### 一个数和一列数

单独一个实数叫标量，例如损失最后剩下的那一个数。排成一列的数叫向量，例如一条样本上的各个特征。若干列并排放在一起叫矩阵，行常常是样本，列是特征。

### 形状写在括号里

形状用括号里的整数表示。长度为 4 的向量写成 (4,)。两行三列的表写成 (2, 3)。读形状时只看这组整数，不看里面的小数是多少。

```numpy norun title="形状先不打印"
# 后文的可运行节才会打印形状
print((2, 3))
```

### 梯度跟参数同形

参数是模型里准备被改动的数。梯度是同形状的另一组数，表示损失对每个参数有多敏感。这一页不做反向传播。只读块记下这个对应，避免和后文的可运行例子混在同一次执行里。

```numpy norun title="梯度先不计算"
# 梯度与参数同形
print("same-shape")
```
